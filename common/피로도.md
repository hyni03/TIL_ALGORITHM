## 문제 설명

XX게임에는 피로도 시스템(0 이상의 정수로 표현합니다)이 있으며, 일정 피로도를 사용해서 던전을 탐험할 수 있습니다. <br>
이때, 각 던전마다 탐험을 시작하기 위해 필요한 "최소 필요 피로도"와 던전 탐험을 마쳤을 때 소모되는 "소모 피로도"가 있습니다. <br>
"최소 필요 피로도"는 해당 던전을 탐험하기 위해 가지고 있어야 하는 최소한의 피로도를 나타내며, "소모 피로도"는 던전을 탐험한 후 소모되는 피로도를 나타냅니다. <br>
예를 들어 "최소 필요 피로도"가 80, "소모 피로도"가 20인 던전을 탐험하기 위해서는 유저의 현재 남은 피로도는 80 이상 이어야 하며, 던전을 탐험한 후에는 피로도 20이 소모됩니다.

이 게임에는 하루에 한 번씩 탐험할 수 있는 던전이 여러개 있는데, 한 유저가 오늘 이 던전들을 최대한 많이 탐험하려 합니다. <br>
유저의 현재 피로도 k와 각 던전별 "최소 필요 피로도", "소모 피로도"가 담긴 2차원 배열 dungeons 가 매개변수로 주어질 때, 유저가 탐험할수 있는 최대 던전 수를 return 하도록 solution 함수를 완성해주세요.

### 제한사항
- k는 1 이상 5,000 이하인 자연수입니다.
- dungeons의 세로(행) 길이(즉, 던전의 개수)는 1 이상 8 이하입니다.
  - dungeons의 가로(열) 길이는 2 입니다.
  - dungeons의 각 행은 각 던전의 ["최소 필요 피로도", "소모 피로도"] 입니다.
  - "최소 필요 피로도"는 항상 "소모 피로도"보다 크거나 같습니다.
  - "최소 필요 피로도"와 "소모 피로도"는 1 이상 1,000 이하인 자연수입니다.
  - 서로 다른 던전의 ["최소 필요 피로도", "소모 피로도"]가 서로 같을 수 있습니다.

## 접근법

이 문제는 단순하게 정렬해서는 풀 수 없는 문제였습니다..

예를 들어 어떤 던전은 최소 필요 피로도는 높지만 실제 소모량은 작을 수도 있고, 반대로 입장 조건은 낮지만 한번 탐험하면 피로도를 많이 소모할 수도 있습니다.

즉, **어떤 순서로 던전을 방문하는지에 따라 결과가 달라집니다.**

이럴때는 가능한 모든 던전 순서를 확인하는 완전탐색으로 접근해야합니다! (사실 이미 분류가 완전탐색이기도 했습니다)

그리고 제일 중요한 거슨 던전의 최대 개수가 '8'개 라는 것! <br>
모든 순서를 탐색하더라고 시간이 충분히 가능할 것입니당

<br>

### DFS + 백트래킹

현재 피로도를 `k`라고 했을 때 아직 방문하지 않은 모든 던전을 확인합니다.

현재 던전을 방문하지 않았고, 현재 피로도가 최소 필요 피로도 이상이면 <br>
해당 던전을 탐험할 수 있습니다. <br>
그럼 방문 처리를 하고 현재 피로도에서 소모 피로도를 빼고 다음 DFS를 호출합니다.

```cpp
for(int i=0; i < dungeons.size(); i++) {    
    if(!visited[i] && k >= need) {
        visited[i] = true;
        
        dfs(k-cost, dungeons, count+1);
        
        visited[i] = false;
    }
}
```


여기서 중요한 것은 DFS가 끝난 뒤

```cpp
visited[i] = false;
```

를 통해 방문 상태를 다시 원래대로 돌려놓는 것입니다.

<br>

## 왜 visited를 다시 false로 바꿔야 할까?

예를 들어 던전이 `A`, `B`, `C` 3개 있다고 했을 때

먼저 `A → B → C` 순서를 탐색했다고 한다면, 
이후에는 `A → C → B` 도 확인해야 합니다.

그런데 `B`를 방문한 상태가 그대로 남아있으면 다음 경우에서 `B`를 다시 선택할 수 없습니다.

따라서

```cpp
visited[i] = true;

dfs(...);

visited[i] = false;
```

처럼 DFS가 끝난 후 상태를 다시 되돌려야 합니다.

이렇게

> 선택 → 탐색 → 선택 취소

과정을 반복하는 방식을 **백트래킹(Backtracking)** 이라고 합니다.

<br>

## 해결법

DFS 함수는 현재 피로도 `k`에서 탐험할 수 있는 최대 던전 수를 반환합니다.

```cpp
int dfs(int k, const vector<vector<int>>& dungeons,
        vector<bool>& visited)
```

현재 상태에서 탐험 가능한 던전을 하나씩 확인합니다.

```cpp
for (int i = 0; i < dungeons.size(); i++) {
    int need = dungeons[i][0];
    int cost = dungeons[i][1];

    if (visited[i] || k < need)
        continue;
```

이미 방문했거나 현재 피로도가 부족한 던전은 넘어갑니다.

<br>

### 1. 던전 선택

탐험 가능한 던전이라면 방문 처리합니다.

```cpp
visited[i] = true;
```

그리고 해당 던전을 탐험했으므로 현재 던전 `1개`와 이후에 탐험할 수 있는 던전 수를 더합니다.

```cpp
1 + dfs(k - cost, dungeons, visited)
```

예를 들어 현재 던전을 방문한 뒤 앞으로 2개의 던전을 더 갈 수 있다면 `현재 던전 1개 + 이후 던전 2개 = 3개` 가 됩니다.

따라서

```cpp
max_count = max(
    max_count,
    1 + dfs(k - cost, dungeons, visited)
);
```

로 최댓값을 갱신합니다.

<br>

### 2. 방문 상태 복구

해당 경우의 탐색이 끝나면

```cpp
visited[i] = false;
```

로 다시 방문하지 않은 상태로 만들어줍니다.

그래야 다른 순서에서도 해당 던전을 사용할 수 있습니다.

<br>

## 최종 결과

### 최종 코드

```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int dfs(int k, const vector<vector<int>>& dungeons,
        vector<bool>& visited) {
    
    int max_count = 0;

    for (int i = 0; i < dungeons.size(); i++) {
        int need = dungeons[i][0];
        int cost = dungeons[i][1];

        if (visited[i] || k < need)
            continue;

        visited[i] = true;

        max_count = max(
            max_count,
            1 + dfs(k - cost, dungeons, visited)
        );

        visited[i] = false;
    }

    return max_count;
}

int solution(int k, vector<vector<int>> dungeons) {
    vector<bool> visited(dungeons.size(), false);

    return dfs(k, dungeons, visited);
}
```
