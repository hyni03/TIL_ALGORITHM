## 문제 설명

각 문제를 해결할 때 비용이 발생하며, 힌트를 보유하고 있다면 해당 문제의 해결 비용을 줄일 수 있다.

문제를 해결한 뒤에는 추가 비용을 지불하여 힌트를 구매할 수 있으며, 구매한 힌트는 이후 문제의 비용에 영향을 준다.

모든 문제를 순서대로 해결하면서 **힌트 구매 비용과 문제 해결 비용의 합을 최소화**해야 한다.

<br>

## 접근법

제한사항에 cost의 최대 개수가 16인 것을 보고 바로 완전탐색 DFS를 활용하는 방법을 생각했다.<br>
각 문제에서 힌트를 구매하는 경우와 구매하지 않는 경우를 모두 탐색하는 방식!!

각 문제에서 선택할 수 있는 경우는 두 가지다.

1. 현재 문제의 힌트를 구매한다.
2. 현재 문제의 힌트를 구매하지 않는다.

현재까지 구매한 힌트의 개수를 `buy_hint` 배열에 저장하면, 각 문제를 해결할 때 적용할 할인 단계를 알 수 있다.

예를 들어 다음과 같은 상태라면,

```text
buy_hint = [0, 2, 1, 0]
```

첫 번째 문제에는 힌트가 없고, 두 번째 문제에는 힌트 2개, 세 번째 문제에는 힌트 1개가 적용된다는 의미다.

<br>

## 해결법

### 1. 현재 문제의 해결 비용 계산

현재 문제에 적용할 힌트 개수를 계산한 뒤 해결 비용을 누적한다.

```cpp
int hint_cnt = min((int)cost[i].size()-1, buy_hint[i]);

total += cost[i][hint_cnt];
```

이때! 최대 사용할 수 있는 할인권의 수는 n-1이기 때문에 min() 함수로 n-1이상이면 모두 n-1로 적용되도록 했다

### 2. 힌트를 구매하는 경우

현재 문제의 힌트를 구매한다면 해당 힌트가 영향을 주는 문제들의 `buy_hint`를 증가시킨다.

```cpp
for(int k=1; k<hint[i].size(); k++)
    buy_hint[hint[i][k]-1]++;
```

그다음 힌트 구매 비용인 `hint[i][0]`을 추가하여 다음 문제를 탐색한다.

```cpp
dfs(cost, hint, buy_hint, i+1, total+hint[i][0]);
```

### 3. 힌트를 구매하지 않는 경우

구매하는 경우의 탐색이 끝났다면 변경했던 `buy_hint`를 원래대로 되돌린다.

```cpp
for(int k=1; k<hint[i].size(); k++)
    buy_hint[hint[i][k]-1]--;
```

이후 힌트를 구매하지 않은 상태로 다음 문제를 탐색한다.

```cpp
dfs(cost, hint, buy_hint, i+1, total);
```


배열을 매번 복사하는 대신 변경한 값만 원상 복구하여 두 가지 선택을 독립적으로 탐색할 수 있는 **백트래킹**을 사용했담

```text
힌트 구매
    ↓
힌트 적용 대상 갱신
    ↓
다음 문제 DFS 탐색
    ↓
변경한 힌트 개수 복구
    ↓
힌트 미구매 DFS 탐색
```


<br>

### 4. 가지치기

모든 경우를 끝까지 탐색할 필요는 없다!

이미 사용한 비용이 지금까지 찾은 최소 비용 이상이라면, 해당 경로에서는 더 좋은 결과를 만들 수 없기 때문에 재귀 호출을 줄이기 위해 가지치기를 추가~

```cpp
if(total >= answer)
    return;
```

## 최종 결과

### 최종 코드

```cpp
#include <string>
#include <vector>
#include <climits>

using namespace std;

int answer = INT_MAX ;

void dfs(const vector<vector<int>>& cost,
         const vector<vector<int>>& hint,
         vector<int>& buy_hint,
         int i, int total) {
    
    if(total >= answer)
        return;
    
    int hint_cnt = min((int)cost[i].size()-1, buy_hint[i]);
    total += cost[i][hint_cnt];
    
    if(i == cost.size() - 1) {
        answer = min(answer, total);
        return;
    }
    
    for(int k=1; k<hint[0].size(); k++){
        buy_hint[hint[i][k]-1] ++;
    }
    dfs(cost, hint, buy_hint, i+1, total+hint[i][0]);
    
    for(int k=1; k<hint[0].size(); k++){
        buy_hint[hint[i][k]-1] --;
    }
    dfs(cost, hint, buy_hint, i+1, total);
    
    return;
} 

int solution(vector<vector<int>> cost, vector<vector<int>> hint) {
    
    vector<int> buy_hint(cost.size(), 0);
    dfs(cost, hint, buy_hint, 0, 0);
    
    return answer;
}
```

### 시간 복잡도 (gpt 피셜)

문제의 개수를 `N`, 한 문제에서 힌트 적용 대상을 처리하는 최대 개수를 `H`라고 할때

각 문제에서 힌트를 구매하거나 구매하지 않는 두 가지 선택이 발생하므로 DFS의 시간 복잡도는 최악의 경우 다음과 같다.

**시간 복잡도: `O(2^N × H)`**

문제 개수는 최대 16개이므로 모든 구매 조합을 고려하더라도 최대 `2^16 = 65,536`가지다.

또한 이미 사용한 비용이 현재 최솟값 이상인 경우 탐색을 중단하는 가지치기가 적용되어 있다.

**추가 공간 복잡도: `O(N)`**

`buy_hint` 배열과 재귀 호출 스택이 필요하다.
