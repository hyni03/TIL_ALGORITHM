## 문제 설명

`m × n` 크기의 사막에 `h × w` 크기의 선인장을 놓으려고 한다.

비는 `drops`에 주어진 순서대로 한 방울씩 떨어지고, 선인장이 차지하고
있는 영역에 빗방울이 떨어지면 선인장이 비를 맞게 된다.

따라서 선인장을 **최대한 늦게 비를 맞을 수 있는 위치**에 놓아야 한다.

<br>

## 기존 풀이

처음 작성한 방식은 다음과 같았다.

``` cpp
for(int i=0; i<=m-h; i++){
    for(int j=0; j<=n-w; j++){
        for(int k=0; k<drops.size(); k++){
            if(i <= drops[k][0] && i+h > drops[k][0] &&
               j <= drops[k][1] && j+w > drops[k][1]) {

                desert_map[i][j] = k+1;
                break;
            }
        }
    }
}
```

선인장을 `(i, j)`에 놓았다고 가정한 뒤,

``` text
drops[0]
drops[1]
drops[2]
...
```

를 순서대로 확인하면서 선인장 영역에 처음 들어오는 빗방울의 번호를
저장했다.

구현 자체는 직관적이었지만...

``` text
선인장 위치 하나 선택
→ drops 전체 확인

다음 위치 선택
→ 다시 drops 전체 확인

다음 위치 선택
→ 또 drops 전체 확인
```

이런 방식으로 같은 `drops`를 계속 반복해서 탐색하게 된다.

선인장을 놓을 수 있는 위치의 수가 많고 `drops`의 크기까지 커지면 시간 복잡도가 너무 커져 결국 시간 초과가 발생했다.

<br>

## 접근법

그렇다면??

선인장 위치마다 `drops`를 확인하지 말고, **각 칸에 몇 번째 빗방울이 떨어지는지를 먼저 저장**하면 어떨까?

예를 들어

``` text
m = 4
n = 5
h = 2
w = 2

drops = [
    [0,0],
    [3,1],
    [1,3],
    [2,4],
    [1,1],
    [2,2],
    [2,3],
    [0,4]
]
```

라면 각 칸에 빗방울이 떨어지는 순서를 저장한 `rain`은 다음과 같다.

|   | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | 1 | INF | INF | INF | 8 |
| 1 | INF | 5 | INF | 3 | INF |
| 2 | INF | INF | 6 | 7 | 4 |
| 3 | INF | 2 | INF | INF | INF |

비가 한 번도 떨어지지 않는 위치는 `INT_MAX`로 저장했다.

이제 선인장을 `(2, 2)`에 놓는다고 생각해보면 선인장이 차지하는 영역은

``` text
6    7
INF  INF
```

이다.

이 영역에 들어오는 빗방울 중 가장 빠른 것은 `6`번째 빗방울이다.

즉,

``` text
선인장이 처음 비를 맞는 시간
= 선인장이 차지하는 h × w 영역의 최솟값
```

이 된다.

따라서 문제를 다음과 같이 바꿔서 생각할 수 있다.

> 모든 `h × w` 영역의 최솟값을 구한 뒤, 그 값이 가장 큰 위치를 찾는다.

<br>

## 2차원 최솟값 구하기

처음에는 각 `h × w` 영역을 직접 탐색해서 최솟값을 구할 수도 있다고 생각했다.

하지만 매 위치마다 `h × w`개의 칸을 다시 확인하면 이것도 비효율적이다.

그래서 2차원 영역을 한 번에 계산하지 않고 `가로 w칸의 최솟값` -> `세로 h칸의 최솟값` 두 단계로 나누어 계산했다.

<br>

### 1. 가로 `w`칸의 최솟값 구하기

위의 `rain` 배열은

``` text
1    INF  INF  INF  8
INF  5    INF  3    INF
INF  INF  6    7    4
INF  2    INF  INF  INF
```

이고 `w = 2`이다.

각 행에서 연속된 두 칸의 최솟값을 구하면 다음과 같다.

첫 번째 행은

``` text
[1, INF]     → 1
[INF, INF]   → INF
[INF, INF]   → INF
[INF, 8]     → 8
```

이므로

``` text
1  INF  INF  8
```

이 된다.

모든 행에 같은 작업을 하면 `row_min`은

          0     1     2     3
  --- ----- ----- ----- -----
  0       1   INF   INF     8
  1       5     5     3     3
  2     INF     6     6     4
  3       2     2   INF   INF

가 된다.

즉,

``` cpp
row_min[i][j]
```

는 `(i, j)`부터 오른쪽으로 `w`칸을 확인했을 때 가장 먼저 비가 오는
시간을 의미한다.

<br>

### 2. 세로 `h`칸의 최솟값 구하기

이제 `row_min`에서 세로로 `h = 2`칸씩 확인한다.

예를 들어 `j = 2`인 열은

``` text
INF
3
6
INF
```

이다.

두 칸씩 최솟값을 구하면

``` text
min(INF, 3) = 3
min(3, 6)   = 3
min(6, INF) = 6
```

이 된다.

같은 방식으로 모든 열을 계산하면 최종적으로

| 선인장 시작 위치 | y=0  | y=1 | y=2 | y=3 |
| ------------ | ---- | --- | --- | --- |
|     x=0      |   1  |  5  |  3  |  3  |
|  x=1         |   5  |  5  |  3  |  3  |
|  x=2         |   2  |  2  | **6** | 4 |

이 된다.

가장 큰 값은 `6`이고 위치는 `(2, 2)`이다.

따라서 정답은 `[2, 2]`

<br>

## 그런데 최솟값을 어떻게 빠르게 구할까?

여기서 각 구간의 최솟값을 매번 처음부터 찾으면 또 반복 연산이 발생한다.

그래서 `deque`를 사용한 **슬라이딩 윈도우 최솟값**을 사용했다.

여기서 `dq`에는 실제 값이 아니라 **인덱스**를 저장한다.

그리고 deque에는 현재 구간에서 앞으로 **최솟값이 될 가능성이 있는인덱스만 유지**한다.

<br>

### 범위를 벗어난 인덱스 제거

``` cpp
while(!dq.empty() && dq.front() <= j-w)
    dq.pop_front();
```

현재 위치가 `j`이고 구간의 크기가 `w`라면 현재 확인하고 있는 범위는

``` text
j-w+1 ~ j
```

이다.

따라서 `j-w` 이하의 인덱스는 더 이상 현재 범위에 포함되지 않으므로 제거한다

즉 `pop_front()`는

> 현재 슬라이딩 윈도우의 범위를 벗어난 값 제거

<br>

### 최솟값 후보가 될 수 없는 값 제거

``` cpp
while(!dq.empty() && rain[i][dq.back()] >= rain[i][j])
    dq.pop_back();
```

예를 들어 deque가 현재 다음 값을 가리키고 있다고 생각해보자.

``` text
3  5  8
```

여기에 새로운 값 `4`가 들어오면

``` text
8 >= 4 → 8 제거
5 >= 4 → 5 제거
3 >= 4 → 중단
```

하여

``` text
3  4
```

만 남긴다.

`5`, `8`보다 새로 들어온 `4`가 더 작고, 더 나중에 범위를 벗어나기 때문에
`5`, `8`은 앞으로 최솟값이 될 일이 없다.

따라서 제거해도 된다.

결과적으로 deque는 실제 값을 기준으로

``` text
작은 값 → 큰 값
```

순서가 유지된다.

그렇기 때문에

``` cpp
rain[i][dq.front()]
```

에는 항상 현재 구간의 최솟값이 위치하게 된다.

정리하면

``` text
pop_front()
→ 범위를 벗어난 인덱스 제거

pop_back()
→ 최솟값 후보가 될 수 없는 인덱스 제거

dq.front()
→ 현재 구간의 최솟값
```

<br>

## 해결법

전체 과정은 다음과 같다.

``` text
drops
  ↓
각 칸에 몇 번째 빗방울이 떨어지는지 저장
  ↓
rain 배열 생성
  ↓
deque를 이용해 가로 w칸의 최솟값 계산
  ↓
row_min 생성
  ↓
deque를 이용해 세로 h칸의 최솟값 계산
  ↓
각 h × w 영역에서 처음 비를 맞는 시간 계산
  ↓
가장 늦게 비를 맞는 위치 선택
```

기존에는

``` text
선인장 위치
→ drops 전체 확인
→ 다음 선인장 위치
→ drops 다시 전체 확인
```

했다면,

개선한 방법에서는 `drops`를 이용해 `rain`을 한 번 만든 뒤 슬라이딩
윈도우로 필요한 최솟값만 계산한다.

<br>

## 최종 결과

### 최종 코드

``` cpp
#include <string>
#include <vector>
#include <deque>
#include <climits>

using namespace std;

vector<int> solution(int m, int n, int h, int w, vector<vector<int>> drops) {

    vector<vector<int>> rain(m, vector<int>(n, INT_MAX));

    for(int i=0; i<drops.size(); i++){
        int x = drops[i][0];
        int y = drops[i][1];

        rain[x][y] = i+1;
    }

    vector<vector<int>> row_min(m, vector<int>(n - w + 1));

    for(int i=0; i<m; i++){
        deque<int> dq;

        for(int j=0; j<n; j++){

            while(!dq.empty() && dq.front() <= j-w)
                dq.pop_front();

            while(!dq.empty() && rain[i][dq.back()] >= rain[i][j])
                dq.pop_back();

            dq.push_back(j);

            if(j >= w-1)
                row_min[i][j-w+1] = rain[i][dq.front()];
        }
    }

    int max_time = -1;
    vector<int> answer(2);

    for(int j=0; j<=n-w; j++){
        deque<int> dq;

        for(int i=0; i<m; i++){

            while(!dq.empty() && dq.front() <= i-h)
                dq.pop_front();

            while(!dq.empty() && row_min[dq.back()][j] >= row_min[i][j])
                dq.pop_back();

            dq.push_back(i);

            if(i >= h-1){
                int x = i-h+1;
                int min_time = row_min[dq.front()][j];

                if(min_time > max_time){
                    max_time = min_time;
                    answer[0] = x;
                    answer[1] = j;
                }

                else if(min_time == max_time){
                    if(x < answer[0] ||
                       (x == answer[0] && j < answer[1])){

                        answer[0] = x;
                        answer[1] = j;
                    }
                }
            }
        }
    }

    return answer;
}
```
