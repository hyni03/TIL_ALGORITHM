# 2026년 9월 26일 TIL - [LV3] 깊이/너비 우선 탐색(DFS/BFS) / 아이템 줍기

링크: https://school.programmers.co.kr/learn/courses/30/lessons/87694

## 문제 설명

다음과 같은 다각형 모양 지형에서 캐릭터가 아이템을 줍기 위해 이동하려 합니다.

<img width="850" height="410" alt="image" src="https://github.com/user-attachments/assets/85760d78-1235-4504-bc3f-ed0f8b921ef8" />

지형은 각 변이 x축, y축과 평행한 직사각형이 겹쳐진 형태로 표현하며, 캐릭터는 이 다각형의 둘레(굵은 선)를 따라서 이동합니다.

<img width="408" height="408" alt="image" src="https://github.com/user-attachments/assets/ab421f10-a24d-4c40-b120-baf8fbf3f11b" />

만약 직사각형을 겹친 후 다음과 같이 중앙에 빈 공간이 생기는 경우, 다각형의 가장 바깥쪽 테두리가 캐릭터의 이동 경로가 됩니다.

단, 서로 다른 두 직사각형의 x축 좌표 또는 y축 좌표가 같은 경우는 없습니다. 서로 다른 두 직사각형이 꼭짓점에서 만나거나, 변이 겹치는 경우 등은 없습니다.

지형이 2개 이상으로 분리된 경우도 없습니다. 한 직사각형이 다른 직사각형 안에 완전히 포함되는 경우 또한 없습니다.

지형을 나타내는 직사각형이 담긴 2차원 배열 rectangle, 초기 캐릭터의 위치 characterX, characterY, 아이템의 위치 itemX, itemY가 solution 함수의 매개변수로 주어질 때, 캐릭터가 아이템을 줍기 위해 이동해야 하는 가장 짧은 거리를 return 하도록 solution 함수를 완성해주세요.


### 제한사항
- rectangle의 세로(행) 길이는 1 이상 4 이하입니다.
- rectangle의 원소는 각 직사각형의 [좌측 하단 x, 좌측 하단 y, 우측 상단 x, 우측 상단 y] 좌표 형태입니다.
  - 직사각형을 나타내는 모든 좌표값은 1 이상 50 이하인 자연수입니다.
  - 서로 다른 두 직사각형의 x축 좌표, 혹은 y축 좌표가 같은 경우는 없습니다.
  - 문제에 주어진 조건에 맞는 직사각형만 입력으로 주어집니다.
- charcterX, charcterY는 1 이상 50 이하인 자연수입니다.
  - 지형을 나타내는 다각형 테두리 위의 한 점이 주어집니다.
- itemX, itemY는 1 이상 50 이하인 자연수입니다.
  - 지형을 나타내는 다각형 테두리 위의 한 점이 주어집니다.
- 캐릭터와 아이템의 처음 위치가 같은 경우는 없습니다.


<br>

## 접근법

전체적인 흐름은 다음과 같습니다.

```text
1. 모든 좌표를 2배 한다.
2. 직사각형 영역 전체를 1로 채운다.
3. 직사각형 내부를 다시 0으로 만든다.
4. 남아있는 테두리만 BFS 한다.
5. 좌표를 2배했으므로 최종 거리를 2로 나눈다.
```

<br>

### 왜 좌표를 2배 해야 할까?

직사각형의 좌표를 그대로 사용하면 서로 다른 테두리가 대각선이나 모서리 부분에서 붙어버리는 경우가 있습니다.

그러면 실제로는 이동할 수 없는 길인데도 BFS에서는 인접한 칸처럼 인식해서 잘못된 경로로 이동할 수 있습니다.

예를 들어 원래 좌표가

```text
(1, 1)
(2, 2)
```

처럼 가까이 있다면 좌표를 2배해서

```text
(2, 2)
(4, 4)
```

로 만들어줍니다.

그러면 좌표 사이에 한 칸의 여유 공간이 생기기 때문에 서로 다른 테두리를 확실하게 구분할 수 있습니다.

그래서 모든 직사각형 좌표와 캐릭터, 아이템 위치를

```cpp
x * 2
y * 2
```

로 바꿔서 사용합니다.

<br>

## 해결법

### 1. 직사각형 전체 영역 채우기

먼저 모든 직사각형의 좌표를 2배한 뒤 해당 범위를 모두 `1`로 채웁니다.

```cpp
for (vector<int> rec : rectangle) {
    int x1 = rec[0] * 2;
    int y1 = rec[1] * 2;
    int x2 = rec[2] * 2;
    int y2 = rec[3] * 2;

    for (int x = x1; x <= x2; x++) {
        for (int y = y1; y <= y2; y++) {
            map[x][y] = 1;
        }
    }
}
```

여기까지 하면 직사각형의 테두리뿐만 아니라 내부까지 전부 `1`인 상태입니다.

<br>

### 2. 직사각형 내부 제거

캐릭터는 직사각형의 내부를 지나갈 수 없고 테두리만 이동할 수 있기 때문에 내부를 다시 `0`으로 만들어줍니다.

```cpp
for (vector<int> rec : rectangle) {
    int x1 = rec[0] * 2;
    int y1 = rec[1] * 2;
    int x2 = rec[2] * 2;
    int y2 = rec[3] * 2;

    for (int x = x1 + 1; x < x2; x++) {
        for (int y = y1 + 1; y < y2; y++) {
            map[x][y] = 0;
        }
    }
}
```

여기서

```cpp
x1 + 1 ~ x2 - 1
y1 + 1 ~ y2 - 1
```

범위만 `0`으로 바꾸기 때문에 직사각형의 테두리는 그대로 `1`로 남습니다.

결과적으로

```text
1 = 이동 가능한 테두리
0 = 이동할 수 없는 곳
```

이 됩니다.

<br>

### 왜 채우기와 내부 제거를 따로 할까?

직사각형들이 서로 겹쳐 있기 때문에 각 직사각형을 하나씩 처리하면서

```text
채우기 → 내부 제거
```

를 바로 해버리는 것보다

```text
모든 직사각형 채우기
→
모든 직사각형 내부 제거
```

순서로 처리하는 것이 안전합니다.

먼저 모든 직사각형이 합쳐진 전체 영역을 만든 뒤 내부를 제거하면 최종적으로 이동 가능한 외곽선만 남길 수 있습니다.

<br>

### 3. BFS

이제 테두리만 `1`로 남아있기 때문에 캐릭터 위치에서 BFS를 시작합니다.

```cpp
queue<pair<int, int>> q;

q.push({sx, sy});
dist[sx][sy] = 0;
```

상하좌우 네 방향으로 이동하면서

```cpp
map[nx][ny] == 1
```

인 곳만 이동합니다.

```cpp
for (int i = 0; i < 4; i++) {
    int nx = x + dx[i];
    int ny = y + dy[i];

    if (nx < 0 || nx >= 102 || ny < 0 || ny >= 102)
        continue;

    if (map[nx][ny] == 0 || dist[nx][ny] != -1)
        continue;

    dist[nx][ny] = dist[x][y] + 1;
    q.push({nx, ny});
}
```

`dist` 배열을 처음에 모두 `-1`로 만들어두고

```cpp
dist[nx][ny] != -1
```

이면 이미 방문한 위치라고 판단합니다.

따라서 별도의 `visited` 배열 없이 `dist` 하나로

```text
방문 여부 + 이동 거리
```

두 가지를 동시에 관리할 수 있습니다. <br>
(원래는 `dist`+`visited`를 따로 뒀었는데 `dist` 배열 하나로 방문 여부와 거리를 같이 관리하니까 조금 더 깔끔해졌습니다.)

<br>

### 4. 최종 거리 / 2

모든 좌표를 처음에 2배했기 때문에 BFS에서 계산되는 거리 역시 실제 거리의 2배입니다.

따라서 아이템 위치에 도착하면

```cpp
return dist[x][y] / 2;
```

해주면 실제 이동 거리를 구할 수 있습니다.

<br>


## 최종 결과

### 최종 코드

```cpp
#include <string>
#include <vector>
#include <queue>
#include <cstring>

using namespace std;

int map[102][102];
int dist[102][102];

int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};

int solution(vector<vector<int>> rectangle,
             int characterX, int characterY,
             int itemX, int itemY) {

    memset(dist, -1, sizeof(dist));

    // 좌표 2배 + 직사각형 전체 채우기
    for (vector<int> rec : rectangle) {
        int x1 = rec[0] * 2;
        int y1 = rec[1] * 2;
        int x2 = rec[2] * 2;
        int y2 = rec[3] * 2;

        for (int x = x1; x <= x2; x++) {
            for (int y = y1; y <= y2; y++) {
                map[x][y] = 1;
            }
        }
    }

    // 직사각형 내부 제거 → 테두리만 남기기
    for (vector<int> rec : rectangle) {
        int x1 = rec[0] * 2;
        int y1 = rec[1] * 2;
        int x2 = rec[2] * 2;
        int y2 = rec[3] * 2;

        for (int x = x1 + 1; x < x2; x++) {
            for (int y = y1 + 1; y < y2; y++) {
                map[x][y] = 0;
            }
        }
    }

    int sx = characterX * 2;
    int sy = characterY * 2;
    int ex = itemX * 2;
    int ey = itemY * 2;

    queue<pair<int, int>> q;

    q.push({sx, sy});
    dist[sx][sy] = 0;

    while (!q.empty()) {
        int x = q.front().first;
        int y = q.front().second;
        q.pop();

        if (x == ex && y == ey)
            return dist[x][y] / 2;

        for (int i = 0; i < 4; i++) {
            int nx = x + dx[i];
            int ny = y + dy[i];

            if (nx < 0 || nx >= 102 || ny < 0 || ny >= 102)
                continue;

            if (map[nx][ny] == 0 || dist[nx][ny] != -1)
                continue;

            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }

    return 0;
}
```
