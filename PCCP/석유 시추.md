## 문제 설명

**[본 문제는 정확성과 효율성 테스트 각각 점수가 있는 문제입니다.]**

세로 길이가 `n`, 가로 길이가 `m`인 격자 모양의 땅 속에서 석유가 발견되었습니다.

석유는 여러 덩어리로 나누어 묻혀있습니다. <br>
당신이 시추관을 수직으로 **단 하나만** 뚫을 수 있을 때, 가장 많은 석유를 뽑을 수 있는 시추관의 위치를 찾으려고 합니다. <br>
시추관은 열 하나를 관통하는 형태여야 하며, 열과 열 사이에 시추관을 뚫을 수 없습니다.

<img width="553" height="209" alt="image" src="https://github.com/user-attachments/assets/c0d819f4-5746-4780-bfaa-5450d1625b66" />

예를 들어 가로가 8, 세로가 5인 격자 모양의 땅 속에 위 그림처럼 석유가 발견되었다고 가정하겠습니다. <br>
상, 하, 좌, 우로 연결된 석유는 하나의 덩어리이며, 석유 덩어리의 크기는 덩어리에 포함된 칸의 수입니다. <br>
그림에서 석유 덩어리의 크기는 왼쪽부터 8, 7, 2입니다.

<img width="585" height="249" alt="image" src="https://github.com/user-attachments/assets/ad9502d3-0825-43d3-bdc3-aaba4a9f9e81" />

시추관은 위 그림처럼 설치한 위치 아래로 끝까지 뻗어나갑니다. <br>
만약 시추관이 석유 덩어리의 일부를 지나면 해당 덩어리에 속한 모든 석유를 뽑을 수 있습니다. 

시추관이 뽑을 수 있는 석유량은 시추관이 지나는 석유 덩어리들의 크기를 모두 합한 값입니다. <br>
시추관을 설치한 위치에 따라 뽑을 수 있는 석유량은 다음과 같습니다.

| 시추관의 위치 | 획득한 덩어리 | 총 석유량 |
| --- | --- | --- |
| 1	| [8]	| 8 |
2	| [8]	| 8
3	| [8]	| 8
4	| [7]	| 7
5	| [7] |	7
6	| [7]	| 7
7	| [7, 2] | 9
8	| [2] |	2

오른쪽 그림처럼 7번 열에 시추관을 설치하면 크기가 7, 2인 덩어리의 석유를 얻어 뽑을 수 있는 석유량이 9로 가장 많습니다.

석유가 묻힌 땅과 석유 덩어리를 나타내는 2차원 정수 배열 land가 매개변수로 주어집니다. <br>
이때 시추관 하나를 설치해 뽑을 수 있는 가장 많은 석유량을 return 하도록 solution 함수를 완성해 주세요.

## 접근법

문제를 처음 봤을 때는 각 열마다 위에서 아래로 내려가면서 석유를 만날 때마다 BFS를 돌리면 되지 않을까?? 생각할 수도 있습니다.

근데 이렇게 하면 같은 석유 덩어리를 여러 열에서 계속 다시 탐색하게 됩니다.

예를 들어 하나의 엄청 큰 석유 덩어리가 여러 열에 걸쳐 있으면

```text
1번 열에서 BFS
2번 열에서 또 BFS
3번 열에서 또 BFS
...
```

가 되어버립니다.

`land`의 크기가 최대 `500 × 500`이기 때문에 효율성 테스트에서 문제가 발생할 수 있습니다.

그래서 저는 **석유 덩어리 자체를 한 번만 BFS로 탐색하고 번호를 부여하는 방식**으로 풀었습니다.

기존 코드에서는

```cpp
v[x][y] = s;
```

와 같이 같은 석유 덩어리에 동일한 번호를 부여하고,

```cpp
sum[s] = land_sum;
```

을 통해 해당 덩어리의 크기를 저장했습니다.

그리고 각 열마다

```cpp
vector<set<int>> vs(501);
```

를 사용해서 해당 열이 어떤 석유 덩어리들과 연결되어 있는지 저장했습니다.

같은 석유 덩어리가 한 열에서 여러 칸을 차지할 수 있기 때문에 `set`을 통해 중복을 제거했습니다.

예를 들어

```text
1번 석유 덩어리 크기 = 8
2번 석유 덩어리 크기 = 7
```

이고 특정 열에서

```text
1번
1번
1번
2번
```

을 만났다고 해도

```text
8 + 8 + 8 + 7
```

이 아니라

```text
8 + 7
```

만 계산해야 하기 때문에 중복 제거가 필요합니다.

일단은 1차로 이렇게 풀었는데요 좀 더 개선할 방안이 있을까 싶어서 한번 더 생각해봤습니다.


<br>

### 기존 풀이에서 개선할 부분

기존 코드는 크게 보면

```text
1. BFS로 석유 덩어리에 번호 부여
2. 석유 덩어리 크기 저장
3. 각 열마다 어떤 덩어리가 존재하는지 set에 저장
4. 마지막에 각 열의 set을 순회하며 석유 크기 합산
```

의 과정으로 되어 있습니다.

그러다 보니

```cpp
int v[501][501];
int sum[250001];

vector<set<int>> vs(501);
```

처럼 관리해야 하는 자료구조 생각보다 많습니다..

특히 `set<int>` 의 삽입 연산은 일반적으로 `O(log N)`인데요! 현재 문제는 시간초과가 나지는 않지만 모든 석유칸을 확인하면서 불필요한 연산이 계속 발생하게 됩니다..!

생각해보면 BFS를 돌면서 이미 `이 석유 덩어리가 몇 칸인지` 와 `이 석유 덩어리가 어떤 열들을 지나가는지` 를 모두 알 수 있습니다.

그렇다면?? BFS가 끝난 후에 바로 해당 열들에 석유 덩어리 크기를 바로 더해주면 됩니다!


`석유 덩어리 → 번호 저장 → set 저장 → 다시 계산`

할 필요 없이

`석유 덩어리 탐색 → 해당 열에 바로 누적`

이런식으로 말이지용용

<br>

## 해결법

전체 `land`를 순회하면서 아직 방문하지 않은 석유 칸을 발견하면 BFS를 시작합니다.

```cpp
if (land[i][j] == 1 && !v[i][j])
```

<br>

### 1. BFS를 통해 하나의 석유 덩어리 크기 구하기

BFS를 시작하면 해당 석유와 상하좌우로 연결된 모든 칸을 탐색합니다.

```cpp
 while (!q.empty()) { 
    int x = q.front().first; 
    int y = q.front().second; 
    q.pop(); 
    
    oil_size++; 
    
    for (int k = 0; k < 4; k++) { 
        int nx = x + dx[k]; 
        int ny = y + dy[k]; 
        
        if (nx < 0 || nx >= n || ny < 0 || ny >= m) 
            continue; 
        
        if (land[nx][ny] == 0 || v[nx][ny]) 
            continue; 
        
        v[nx][ny] = 1; 
        q.push({nx, ny}); 
    } 
} 
```
한 칸을 방문할 때마다 `oil_size++;` 를 해주면 해당 석유 덩어리의 크기를 구할 수 있습니다.

### 2. 해당 석유 덩어리가 지나가는 열 저장

여기서 중요한 점은 하나의 석유 덩어리가 같은 열에 여러 칸 존재하더라도 해당 덩어리의 크기는 한 번만 더해야 한다는 것입니다.

예를 들어

```
0 1 0
0 1 0
0 1 0
```

이라면 2번 열에는 석유가 3칸 있지만 모두 하나의 덩어리입니다. <br>
따라서 `3 + 3 + 3` 이 아니라 `3`만 추가해야 합니다!!

기존에는 이 중복 제거를 위해 set을 사용했는데요,, 개선한 코드에서는 col_check 배열을 이용했습니다

또 BFS 중에 현재 열이 이번 석유 덩어리에서 이미 저장된 열인지 체크합니다

```cpp
if (col_check[y] != oil_num) {
    col_check[y] = oil_num;
    cols.push_back(y);
}
```

같은 석유 덩어리를 탐색하는 동안 이미 확인한 열이라면 cols에 다시 넣지 않도록 해서 `set` 없이도 중복 여부를 확인할 수 있는 것이지요

<br>

### 3. BFS가 끝나면 각 열에 석유량 누적

BFS가 끝났다면 현재 석유 덩어리의 전체 크기 `oil_size`를 알 수 있습니다.

그리고 이 석유 덩어리가 지나가는 열들은 `cols`에 저장되어 있습니다.

따라서
```cpp
for (int col : cols)
    col_sum[col] += oil_size;
```
해주면 됩니다.

여기서 `col_sum[i]`은 i 번째 열에 시추관을 설치했을 때 얻을 수 있는 전체 석유량입니다!

예를 들어 크기가 8인 석유 덩어리가 0, 1, 2번 열에 걸쳐 있다면

```
col_sum[0] += 8;
col_sum[1] += 8;
col_sum[2] += 8;
```

이 됩니다.

이후 다른 석유 덩어리가 같은 열에 걸쳐 있으면 그 석유의 크기도 추가됩니다.

## 최종 결과

### 최종 코드

```cpp
#include <string> 
#include <vector> 
#include <queue> 
#include <algorithm> 

using namespace std; 
    
int dx[4] = {0, 1, 0, -1}, dy[4] = {1, 0, -1, 0}; 

int solution(vector<vector<int>> land) { 
    int n = land.size(); 
    int m = land[0].size(); 
    
    vector<vector<int>> v(n, vector<int>(m, 0)); 
    vector<int> col_sum(m, 0); 
    vector<int> col_check(m, 0); 
    
    int oil_num = 0; 
    
    for (int i = 0; i < n; i++) { 
        for (int j = 0; j < m; j++) { 
            if (land[i][j] == 0 || v[i][j]) 
                continue; oil_num++; 
            
            queue<pair<int, int>> q; 
            vector<int> cols; 
            
            int oil_size = 0; 
            
            v[i][j] = 1; 
            q.push({i, j}); 
            
            while (!q.empty()) { 
                int x = q.front().first; 
                int y = q.front().second; 
                q.pop(); 
                
                oil_size++; 
                
                if (col_check[y] != oil_num) { 
                    col_check[y] = oil_num; 
                    cols.push_back(y); 
                } 
                
                for (int k = 0; k < 4; k++) { 
                    int nx = x + dx[k]; 
                    int ny = y + dy[k]; 
                    
                    if (nx < 0 || nx >= n || ny < 0 || ny >= m) 
                        continue; 
                    
                    if (land[nx][ny] == 0 || v[nx][ny]) 
                        continue; 
                    
                    v[nx][ny] = 1; 
                    q.push({nx, ny}); 
                } 
            } 
            
            for (int col : cols) 
                col_sum[col] += oil_size; 
        } 
    } 

    return *max_element(col_sum.begin(), col_sum.end()); 
}
```

굳이 석유 덩어리 번호를 저장하고 나중에 다시 찾아서 계산할 필요 없이 <br>
