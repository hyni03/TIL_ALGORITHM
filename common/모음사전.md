## 문제 설명

사전에 알파벳 모음 'A', 'E', 'I', 'O', 'U'만을 사용하여 만들 수 있는, 길이 5 이하의 모든 단어가 수록되어 있습니다. <br>
사전에서 첫 번째 단어는 "A"이고, 그다음은 "AA"이며, 마지막 단어는 "UUUUU"입니다.

단어 하나 word가 매개변수로 주어질 때, 이 단어가 사전에서 몇 번째 단어인지 return 하도록 solution 함수를 완성해주세요.

### 제한사항
- word의 길이는 1 이상 5 이하입니다.
- word는 알파벳 대문자 'A', 'E', 'I', 'O', 'U'로만 이루어져 있습니다.

<br>

## 접근법

처음에는 모든 단어를 직접 만들어서 사전 순서대로 저장한 다음 원하는 단어를 찾는 완전탐색 방법을 있습니다. (애초에 문제 분류도 완전탐색...)

근데 굳이 모든 단어를 만들지 않아도 **각 자리의 알파벳이 바뀔 때 몇 개의 단어를 건너뛰는지** 계산하면 바로 사전의 순서를 구할 수 있습니다.

예를 들어 첫 번째 글자가 `A → E`로 바뀐다면 `A`로 시작하는 단어들을 전부 건너뛰어야 합니다.

그렇다면 `A`로 시작하는 단어가 몇 개인지만 알면 되는 것!!

<br>

## 해결법 (가중치 구하기)

각 자리에서 다음 알파벳으로 넘어갈 때 몇 개의 단어를 건너뛰는지 계산해봅시당

### 1번째 자리

첫 번째 글자를 하나 고정했다고 했을때

예를 들어 `A`로 시작하는 단어는

```text
A

AA
AE
AI
AO
AU

AAA
AAE
...
```

처럼 뒤에 최대 4글자를 더 붙일 수 있습니다. _(총 5글자 제한이기 때문에)_

따라서 `A`로 시작하는 단어의 개수는

```text
1 + 5 + 5² + 5³ + 5⁴
= 1 + 5 + 25 + 125 + 625
= 781
```
이 됩니다.


즉 첫 번째 글자가 `A → E`로 변경되면 `A`로 시작하는 `781`개의 단어를 건너뛰게 되는 것이지요

<br>

### 2번째 자리

첫 번째 글자는 이미 정해져 있으므로 뒤에 최대 3글자를 추가할 수 있습니다.

```text
1 + 5 + 25 + 125
= 156
```

따라서 두 번째 자리의 가중치는 `156`입니다.

<br>

같은 방식으로 계산하면

```text
1번째 자리 : 781 = 1 + 5 + 25 + 125 + 625
2번째 자리 : 156 = 1 + 5 + 25 + 125
3번째 자리 :  31 = 1 + 5 + 25
4번째 자리 :   6 = 1 + 5
5번째 자리 :   1
```

이 됩니다.

그래서 코드에서는 

```cpp
vector<int> weight = {781, 156, 31, 6, 1};
```

로 배열?벡터로 가중치 자체를 미리 저장했습니다.

<br>

## 알파벳 순서 계산

모음은 사전순으로

```text
A E I O U
0 1 2 3 4
```

라고 생각할 수 있습니다.

따라서

```cpp
string alpha = "AEIOU";
```

를 만들어두고

```cpp
int idx = alpha.find(word[i]);
```

로 현재 알파벳이 몇 번째인지 구합니다.

예를 들어

```text
A → 0
E → 1
I → 2
O → 3
U → 4
```

가 됩니다.

현재 자리의 알파벳 앞에 있는 단어 묶음의 개수는 `idx * weight[i+1]`로 계산할 수 있습니다.

다른 모음을 구할 때를 예로 들면! <br>
첫 번째 자리에서는 각 모음으로 시작하는 단어 묶음의 크기가 모두 781개입니다. <br>
따라서 `E`로 시작한다면 앞의 `A` 묶음 `781`개를 건너뛰고, `I`로 시작한다면 `A`, `E` 두 묶음을 건너뛰므로 `781 × 2`가 됩니다.


<br>

## 왜 +1을 할까?

처음에는

```cpp
answer += idx * weight[i];
```

만 하면 될 것 같지만 각 자리마다 `+ 1`이 필요합니다.

예를 들어 단어가 `A` 라면 `idx = 0`이기 때문에

```text
0 * 781 = 0
```

이 됩니다.

하지만 `A`는 사전의 **첫 번째 단어**이므로 정답은 1이어야 합니다.

따라서 현재 글자까지 만들어진 단어 자체를 포함하기 위해

```cpp
answer += idx * weight[i] + 1;
```

을 해줘야합니다

<br>

## 예시

```text
word = "EIO"
```

를 계산해보겠습니다.


<br>

### E

`E`는 모음 중 인덱스가 `1`입니다.

```text
1 × 781 + 1
= 782
```

### I

`I`는 인덱스가 `2`입니다.

```text
2 × 156 + 1
= 313
```

### O

`O`는 인덱스가 `3`입니다.

```text
3 × 31 + 1
= 94
```

<br>

따라서 모든 값을 더해주면

```text
782 + 313 + 94
= 1189
```

정답은 `1189`가 됩니다.

<br>

## 최종 결과

### 최종 코드

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(string word) {
    int answer = 0;
    
    string alpha = "AEIOU";
    vector<int> weight = {781, 156, 31, 6, 1};
    
    for (int i = 0; i < word.length(); i++) {
        int idx = alpha.find(word[i]);

        answer += idx * weight[i] + 1;
    }
    
    return answer;
}
```

## DFS로도 풀 수 있다

이 문제는 완전탐색 문제이기 때문에 DFS를 이용해서 실제 사전의 모든 단어를 만들어도 풀 수 있는데요
모음은 5개이고 최대 길이도 5이기 때문에 실제로 만들어지는 단어의 수는 많지 않아서 DFS로 전부 생성해도 충분히 풀 수 있습니다.


예를 들어

```text
""
↓
A
↓
AA
↓
AAA
...
```

와 같이 현재 문자열 뒤에

```text
A
E
I
O
U
```

를 하나씩 추가하며 깊이 5까지 탐색하면 됩니다.

만들어진 단어를 순서대로 확인하면서 `word`를 발견하면 현재 순서를 반환하는 방식입니다.

하지만 이 문제에서는 사전의 구조가 일정하기 때문에 모든 단어를 실제로 만들기보다

> 각 자리에서 몇 개의 단어를 건너뛰는가?

를 계산하는 방법이 훨씬 간단했습니다.

<br>
