## 문제 설명
어떤 게임에는 `붕대 감기`라는 기술이 있습니다.

`붕대 감기`는 `t`초 동안 붕대를 감으면서 1초마다 `x`만큼의 체력을 회복합니다. <br>
`t`초 연속으로 붕대를 감는 데 성공한다면 `y`만큼의 체력을 추가로 회복합니다. <br> 
게임 캐릭터에는 최대 체력이 존재해 현재 체력이 최대 체력보다 커지는 것은 불가능합니다.

기술을 쓰는 도중 몬스터에게 공격을 당하면 기술이 취소되고, 공격을 당하는 순간에는 체력을 회복할 수 없습니다. <br>
몬스터에게 공격당해 기술이 취소당하거나 기술이 끝나면 그 즉시 `붕대 감기`를 다시 사용하며, 연속 성공 시간이 0으로 초기화됩니다.

몬스터의 공격을 받으면 정해진 피해량만큼 현재 체력이 줄어듭니다. 이때, 현재 체력이 0 이하가 되면 캐릭터가 죽으며 더 이상 체력을 회복할 수 없습니다.

당신은 `붕대 감기` 기술의 정보, 캐릭터가 가진 최대 체력과 몬스터의 공격 패턴이 주어질 때 캐릭터가 끝까지 생존할 수 있는지 궁금합니다.

`붕대 감기` 기술의 시전 시간, 1초당 회복량, 추가 회복량을 담은 1차원 정수 배열 `bandage`와 최대 체력을 의미하는 정수 `health`, 몬스터의 공격 시간과 피해량을 담은 2차원 정수 배열 `attacks`가 매개변수로 주어집니다. <br>
모든 공격이 끝난 직후 남은 체력을 return 하도록 solution 함수를 완성해 주세요.

**만약 몬스터의 공격을 받고 캐릭터의 체력이 0 이하가 되어 죽는다면 -1을 return 해주세요.**


### 제한사항
- `bandage`는 [`시전 시간`, `초당 회복량`, `추가 회복량`] 형태의 길이가 3인 정수 배열입니다.
  - 1 ≤ `시전 시간` = `t` ≤ 50
  - 1 ≤ `초당 회복량` = `x` ≤ 100
  - 1 ≤ `추가 회복량` = `y` ≤ 100
- 1 ≤ `health` ≤ 1,000
- 1 ≤ `attacks`의 길이 ≤ 100
  - `attacks[i]`는 [`공격 시간`, `피해량`] 형태의 길이가 2인 정수 배열입니다.
  - `attacks`는 `공격 시간`을 기준으로 오름차순 정렬된 상태입니다.
  - `attacks`의 `공격 시간`은 모두 다릅니다.
  - 1 ≤ `공격 시간` ≤ 1,000
  - 1 ≤ `피해량` ≤ 100

<br>

## 접근법

마지막 공격 시간을 보시면 최대 1000초 이기 때문에 그냥 시간을 1초씩 증가시키면서

1. 지금 시간이 공격 시간인가?
2. 공격이면 체력 감소
3. 공격이 아니면 체력 회복
4. 연속으로 t초 동안 회복했다면 추가 회복

위의 구조로 풀었습니다.

근데 사실 굳이 공격이 없는 시간까지 1초씩 확인할 필요는 없어서.. 시간을 좀 줄여보고자 수정을 했는데요

attacks가 공격 시간을 기준으로 이미 오름차순 되어 있고, 공격을 받는 순간 연속 붕대 시간이 초기화 되기 때문에,

**이전 공격과 현재 공격 사이에 몇 초 동안 붕대를 감았는가?**

만 계산하면 되는 문제였습니다...

기존 코드
```cpp
// while 문 내
else {
    x += 1;
    if(answer < health){
        answer = min(answer + bandage[1], health);
        if(x == bandage[0]){
            answer = min(answer + bandage[2], health);
            x = 0;
        }
    }
}
```
기존에는 연속 성공 시간을 의미하는 x를 직접 관리했는데용.. <br>
이 방법도 정답 처리되긴 했지만...  x, time, i 등을 동시에 관리해야 해서 생각해야 할 상태가 좀 많아집니다..

특히 최대 채력인 경우에도 붕대를 감은 시간 자체는 계속 흐르므로!!! 아예 연속 시간을 계산하지 않는 방법이 더 깔끔하다고 생각했웁니다.

<br>

### 해결법

이전 공격 시간을 prev_time, 현재 공격 시간을 attack_time이라고 하면

두 공격 사이에서 실제로 붕대를 감을 수 있는 시간은 
```cpp
int heal_time = attack_time - prev_time - 1;
```
입니다. (현재 공격 시간에는 붕대 감을 수 없으므로 -1 !!)

이 후에 기본 회복량과 연속 성공 추가 회복 처리를 해줍니다..!

1. 기본 회복량
heal_time * bandage[1]

2. 연속 성공 추가 회복
붕대 시전 시간이 bandage[0]이라고 하면 <br>
heal_time / bandage[0] 번 연속 성공이 발생합니다!

따라서 추가 회복량은
```cpp
(heal_time / bandage[0]) * bandage[2]
```
가 됩니다.

최종 적으로 총 회복량은 위에 1, 2번을 더 한 것이구요 <br>
최대 체력을 넘을 수 없으므로 min 처리도 해주었습니다.
```cpp
current_health = min(health, current_health + heal_time * bandage[1] + (heal_time / bandage[0]) * bandage[2]);
```

3. 공격 처리

회복을 모두 계산한 뒤에는 공격 피해량을 빼주어야 합니다.

```cpp
current_health -= attack[1];
```

공격 직후 체력이 0 이하라면 바로 -1을 return 해줍니다.

마지막으로!!! 현재 공격 시간을 다음 계산을 위해 저장해주면 됩니다
```cpp
prev_time = attack[0]
```



## 최종 결과


### 최종 코드
```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int solution(vector<int> bandage, int health, vector<vector<int>> attacks) {
    int current_health = health;
    int prev_time = 0;
    
    for (const vector<int>& attack : attacks){
        int attack_time = attack[0];
        int damage = attack[1];

        int heal_time = attack_time - prev_time - 1;
        int total_heal = heal_time * bandage[1] + (heal_time / bandage[0]) * bandage[2];
        
        current_health = min(health, current_health + total_heal);
        
        current_health -= damage;
        
        if (current_health <= 0)
            return -1;
        
        prev_time = attack_time;
    }
    
    return current_health;
}
```
