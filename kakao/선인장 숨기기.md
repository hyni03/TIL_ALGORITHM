## 문제 설명

`m × n` 크기의 사막에 `h × w` 크기의 선인장을 놓아야 한다.

`drops`에 주어진 순서대로 빗방울이 떨어지고, 선인장이 차지하는 칸에 빗방울이 떨어지면 비를 맞게 된다.

따라서 **선인장이 최대한 늦게 비를 맞을 수 있는 위치**를 찾아야 한다.
같은 시점이라면 **행 번호가 작은 위치, 그다음 열 번호가 작은 위치**를 선택한다.

<br>

## 접근법

### 기존 풀이 — 선인장 위치마다 빗방울 확인

처음에는 선인장을 놓을 수 있는 모든 `(i, j)`를 순회하면서, 해당 영역에 처음 들어오는 빗방울의 번호를 구했다.

``` cpp
for(int i=0; i<=m-h; i++){
    for(int j=0; j<=n-w; j++){
        for(int k=0; k<drops.size(); k++){
            if(i <= drops[k][0] && i+h > drops[k][0] &&
               j <= drops[k][1] && j+w > drops[k][1]) {
                desert_map[i][j] = k+1;
                break;
            }
        }
    }
}
```

이렇게 하면

``` text
선인장 (0,0) → drops 처음부터 확인
선인장 (0,1) → drops 다시 처음부터 확인
선인장 (0,2) → drops 또 처음부터 확인
...
```

하게 된다. 선인장을 놓을 수 있는 위치의 개수를 `P`, 빗방울의 개수를 `K`라고 하면 최악의 시간 복잡도는 `O(P × K)`다. <br>
같은 `drops`를 반복해서 확인하니까 시간 초과가 발생했다.

### 발상의 전환!

그렇다면?? **각 칸에 몇 번째 빗방울이 떨어지는지를 먼저 저장**하면 어떨까?

``` cpp
vector<vector<int>> rain(m, vector<int>(n, INT_MAX));

for(int i=0; i<drops.size(); i++){
    int x = drops[i][0];
    int y = drops[i][1];
    rain[x][y] = i+1;
}
```

`INT_MAX`는 비가 떨어지지 않는 칸을 의미한다.

이제 선인장을 `(i, j)`에 놓았을 때 처음 비를 맞는 시간은 **해당 `h × w` 영역에 들어 있는 값의 최솟값**이 된다.

> 선인장이 처음 비를 맞는 시점 = `h × w` 영역의 최솟값

결국 **모든 `h × w` 영역의 최솟값을 구한 다음, 그중 최댓값을 찾는 문제**로 바뀐다!

<br>

## 예제로 이해하기

``` text
m = 4, n = 5
h = 2, w = 2

drops = [
    [0,0], [3,1], [1,3], [2,4],
    [1,1], [2,2], [2,3], [0,4]
]

정답 = [2,2]
```

빗방울의 순서를 저장한 `rain` 배열은 다음과 같다.

| 행 \\ 열 |   0 |   1 |   2 |   3 |   4 |
|----------|----:|----:|----:|----:|----:|
| **0**    |   1 | INF | INF | INF |   8 |
| **1**    | INF |   5 | INF |   3 | INF |
| **2**    | INF | INF |   6 |   7 |   4 |
| **3**    | INF |   2 | INF | INF | INF |

예를 들어 선인장을 `(2,2)`에 놓으면 영역은

``` text
6    7
INF  INF
```

이므로 최솟값은 `6`이다. 즉 **6번째 빗방울이 떨어질 때 처음 비를 맞는다.**

하지만 모든 위치에서 `h × w`칸을 직접 탐색하면 또 비효율적이기 때문에 2차원 최솟값을 다음 두 단계로 나누었다.

``` text
가로 w칸의 최솟값
        ↓
세로 h칸의 최솟값
```

<br>

## 해결법

### 1. 가로 `w`칸의 최솟값 계산

`w = 2`이므로 각 행에서 연속된 두 칸의 최솟값을 구한다.

첫 번째 행을 보면

``` text
rain[0] = [1, INF, INF, INF, 8]

[1, INF]   → 1
[INF, INF] → INF
[INF, INF] → INF
[INF, 8]   → 8
```

따라서 첫 번째 행의 결과는 `[1, INF, INF, 8]`이다. 모든 행에 같은 작업을 수행하면 `row_min`은 다음과 같다.

| 행 \\ 시작 열 |   0 |   1 |   2 |   3 |
|---------------|----:|----:|----:|----:|
| **0**         |   1 | INF | INF |   8 |
| **1**         |   5 |   5 |   3 |   3 |
| **2**         | INF |   6 |   6 |   4 |
| **3**         |   2 |   2 | INF | INF |

`row_min[i][j]`는 **`rain`의 `(i, j)`에서 오른쪽으로 `w`칸을 봤을 때의 최솟값**이다.

### 2. 세로 `h`칸의 최솟값 계산

이번에는 `row_min`에서 세로로 `h = 2`칸씩 확인한다.

예를 들어 `j = 2`열은

``` text
INF
3
6
INF
```

이므로

``` text
min(INF, 3) = 3  → 시작 위치 (0,2)
min(3, 6)   = 3  → 시작 위치 (1,2)
min(6, INF) = 6  → 시작 위치 (2,2)
```

가 된다. 모든 열을 처리하면 최종적으로

| 시작 행 \\ 열 |   0 |   1 |     2 |   3 |
|---------------|----:|----:|------:|----:|
| **0**         |   1 |   5 |     3 |   3 |
| **1**         |   5 |   5 |     3 |   3 |
| **2**         |   2 |   2 | **6** |   4 |

를 얻는다. 최댓값 `6`의 위치는 `(2,2)`이므로 정답은 `[2,2]`!

<br>

## deque를 사용하는 이유

가로 또는 세로 구간의 최솟값을 매번 전부 확인하지 않기 위해 **deque를 활용한 슬라이딩 윈도우 최솟값**을 사용했다.

``` cpp
deque<int> dq;
```

여기서 `dq`에는 빗방울 순서 자체가 아니라 **배열의 인덱스**를 저장한다.
그리고 현재 구간에서 앞으로 최솟값이 될 가능성이 있는 인덱스만 유지한다.

### `pop_front()` — 범위를 벗어난 인덱스 제거

``` cpp
while(!dq.empty() && dq.front() <= j-w)
    dq.pop_front();
```

현재 `j`에서 너비 `w`인 구간은 `[j-w+1, ..., j]`이다. 따라서 `j-w`
이하의 인덱스는 범위를 벗어났으므로 앞에서 제거한다.

### `pop_back()` — 최솟값 후보가 될 수 없는 인덱스 제거

``` cpp
while(!dq.empty() && rain[i][dq.back()] >= rain[i][j])
    dq.pop_back();
```

예를 들어 deque가 가리키는 값이 `[3, 5, 8]`인데 새로운 값 `4`가 들어오면

``` text
8 >= 4 → 8 제거
5 >= 4 → 5 제거
3 >= 4 → 중단

결과: [3, 4]
```

가 된다. 새로 들어온 `4`가 더 작고 더 늦게 범위를 벗어나므로 `5`, `8`은 앞으로 최솟값이 될 수 없다. <br>
같은 값이어도 더 최근 인덱스를 남기는 편이 유리하다.

이렇게 하면 deque가 가리키는 값은 **앞에서 뒤로 갈수록 커지는 순서**를 유지한다. <br>
따라서 `rain[i][dq.front()]`가 현재 구간의 최솟값이 된다.

### 실제 실행 순서

`rain[0] = [1, INF, INF, INF, 8]`, `w = 2`인 경우를 따라가 보자.

| `j` | 새로 읽은 값 | 처리 후 `dq` (인덱스) |     구간 최솟값 |
|----:|-------------:|-----------------------|----------------:|
|   0 |            1 | `[0]`                 | 아직 2칸 미완성 |
|   1 |          INF | `[0,1]`               |               1 |
|   2 |          INF | `[2]`                 |             INF |
|   3 |          INF | `[3]`                 |             INF |
|   4 |            8 | `[4]`                 |               8 |

- `j=2`: 인덱스 `0`이 범위를 벗어나 `pop_front()`. 기존 `INF`는 새 `INF`와 같으므로 `pop_back()` 후 인덱스 `2`를 추가한다.
- `j=3`: 기존 `INF`를 제거하고 새 인덱스 `3`만 남긴다.
- `j=4`: 기존 `INF`보다 새 값 `8`이 작으므로 기존 인덱스를 제거하고 `4`를 추가한다.

그래서 `row_min[0] = [1, INF, INF, 8]`이 완성된다.

정리하면!

``` text
pop_front() → 범위를 벗어난 인덱스 제거
pop_back()  → 최솟값 후보가 될 수 없는 인덱스 제거
dq.front()  → 현재 구간의 최솟값을 가리키는 인덱스
```

### 3. 가장 좋은 위치 선택

세로 방향에서도 같은 방식으로 `deque`를 사용한다.

``` cpp
int x = i-h+1;
int min_time = row_min[dq.front()][j];
```

`min_time`이 더 크면 답을 갱신하고, 같으면 행 번호가 작은 위치를, 행 번호도 같으면 열 번호가 작은 위치를 선택한다.

``` cpp
if(min_time > max_time){
    max_time = min_time;
    answer[0] = x;
    answer[1] = j;
}
else if(min_time == max_time){
    if(x < answer[0] ||
       (x == answer[0] && j < answer[1])){
        answer[0] = x;
        answer[1] = j;
    }
}
```

현재 코드는 **열 `j`를 바깥쪽 반복문에서 먼저 순회**하므로, 동점일 때 좌표 비교가 필요하다.

## 최종 결과

### 최종 코드

``` cpp
#include <string>
#include <vector>
#include <deque>
#include <climits>

using namespace std;

vector<int> solution(int m, int n, int h, int w, vector<vector<int>> drops) {
    
    vector<vector<int>> rain(m, vector<int>(n, INT_MAX));
    
    for(int i=0; i<drops.size(); i++){
        int x = drops[i][0];
        int y = drops[i][1];
        
        rain[x][y] = i+1;
    }
    
    vector<vector<int>> row_min(m, vector<int>(n - w + 1));
    
    for(int i=0; i<m; i++){
        deque<int> dq;
        for(int j=0; j<n; j++){
            
            while(!dq.empty() && dq.front() <= j-w)
                dq.pop_front();
            
            while(!dq.empty() && rain[i][dq.back()] >= rain[i][j])
                dq.pop_back();
            
            dq.push_back(j);
            
            if(j >= w-1)
                row_min[i][j-w+1] = rain[i][dq.front()];
            
        }
    }
    
    int max_time = -1;
    vector<int> answer(2);

    for(int j=0; j<=n-w; j++){
        deque<int> dq;
        for(int i=0; i<m; i++){
            while(!dq.empty() && dq.front() <= i-h)
                dq.pop_front();
            
            while(!dq.empty() && row_min[dq.back()][j] >= row_min[i][j])
                dq.pop_back();
            
            dq.push_back(i);

            if (i >= h - 1) {
                int x = i - h + 1;
                int min_time = row_min[dq.front()][j];

                if (min_time > max_time) {
                    max_time = min_time;
                    answer[0] = x;
                    answer[1] = j;

                }

                else if (min_time == max_time) {
                    if (x < answer[0] ||
                        (x == answer[0] && j < answer[1])) {
                        answer[0] = x;
                        answer[1] = j;
                    }
                }
            }
        }
    }
    
    return answer;
}
```

### 시간 복잡도

`K = drops.size()`라고 하면 다음과 같다.

| 단계                         | 시간 복잡도        |
|------------------------------|--------------------|
| `rain` 초기화 및 빗방울 기록 | `O(m × n + K)`     |
| 가로 슬라이딩 윈도우         | `O(m × n)`         |
| 세로 슬라이딩 윈도우         | `O(m × (n-w+1))`   |
| **전체**                     | **`O(m × n + K)`** |

각 인덱스는 deque에 한 번 들어가고 최대 한 번 제거되므로, 내부에 `while`문이 있어도 전체 슬라이딩 윈도우는 선형 시간에 처리된다.

**공간 복잡도: `O(m × n)`** — `rain`과 `row_min` 배열을 사용한다.
