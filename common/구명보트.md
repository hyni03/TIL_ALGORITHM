## 문제 설명

무인도에 갇힌 사람들을 구명보트를 이용하여 구출하려고 합니다. 구명보트는 작아서 한 번에 최대 2명씩 밖에 탈 수 없고, 무게 제한도 있습니다.

예를 들어, 사람들의 몸무게가 [70kg, 50kg, 80kg, 50kg]이고 구명보트의 무게 제한이 100kg이라면 2번째 사람과 4번째 사람은 같이 탈 수 있지만 1번째 사람과 3번째 사람의 무게의 합은 150kg이므로 구명보트의 무게 제한을 초과하여 같이 탈 수 없습니다.

구명보트를 최대한 적게 사용하여 모든 사람을 구출하려고 합니다.

사람들의 몸무게를 담은 배열 people과 구명보트의 무게 제한 limit가 매개변수로 주어질 때, 모든 사람을 구출하기 위해 필요한 구명보트 개수의 최솟값을 return 하도록 solution 함수를 작성해주세요.

### 제한사항
- 무인도에 갇힌 사람은 1명 이상 50,000명 이하입니다.
- 각 사람의 몸무게는 40kg 이상 240kg 이하입니다.
- 구명보트의 무게 제한은 40kg 이상 240kg 이하입니다.
- 구명보트의 무게 제한은 항상 사람들의 몸무게 중 최댓값보다 크게 주어지므로 사람들을 구출할 수 없는 경우는 없습니다.

<br>

## 접근법

누굴 누구랑 태워야 보트를 최소로 사용할 수 있을까?? <br>
보트에는 최대 2명만 탈 수 있기 때문에 `결국 한 명씩 태울 것인가?` `두 명씩 태울 것인가?` 를 결정하는 문제입니다.

당연히 두 명을 최대한 많이 같이 태우는 것이 좋습니다.

그렇다면 아무 두 명이나 같이 태우면 될까??

예를 들어

```text
people = [40, 50, 60, 90]
limit = 100
```

라고 한다면 가벼운 사람끼리 먼저 `40 + 50 = 90` 으로 태워버리면 <br>
`60 90`은 각각 혼자 타야 해서 총 **3**개의 보트가 필요합니다.

반면 가장 무거운 사람부터 생각하면

```text
90 → 40과 같이 탈 수 없음 → 혼자
60 + 40 = 100
50 → 혼자
```

마찬가지로 3개이긴 하지만, 중요한 점은 **가장 무거운 사람을 누구와 태울 수 있는지 먼저 판단해야 합니다.** <br>
그리고 가장 무거운 사람은 현재 남아있는 사람 중 가장 가벼운 사람과도 같이 탈 수 없다면 다른 누구와도 같이 탈 수 없습니다.

그래서 먼저 사람들의 몸무게를 정렬하고

```text
가장 가벼운 사람 ← l
가장 무거운 사람 ← r
```

위에 처럼 **이중 포인터**를 사용해서 풀었습니다!

<br>

## 해결법

먼저 사람들의 몸무게를 오름차순으로 정렬합니다. <br>
그리고 항상 **가장 무거운 사람 `people[r]`은 이번 보트에 태웁니다.**

그리고 가장 가벼운 사람 `people[l]`과 함께 탈 수 있는지만 확인합니다.

<br>

### 1. 둘이 같이 탈 수 있는 경우

```cpp
if (people[l] + people[r] <= limit)
```

이라면 두 사람을 같은 보트에 태울 수 있습니다.

<br>

### 2. 둘이 같이 탈 수 없는 경우

만약

```cpp
people[l] + people[r] > limit
```

이라면 가장 무거운 사람은 혼자 타야 합니다.

`people[l]`은 현재 남은 사람 중 **가장 가벼운 사람**이기 때문인데용  <br>
가장 가벼운 사람과도 같이 탈 수 없다면 다른사람과의 조합은 무조건 더 무거워지기 때문에 누구와도 같이 탈 수 없게 됩니다.

<br>

## 최종 결과

### 최종 코드

```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int solution(vector<int> people, int limit) {
    int answer = 0;
    
    int l = 0;
    int r = people.size() - 1;
    
    sort(people.begin(), people.end());
    
    while (l <= r) {
        // 가장 가벼운 사람과 가장 무거운 사람이 같이 탈 수 있다면
        if (people[l] + people[r] <= limit)
            l++;
        
        // 가장 무거운 사람은 무조건 현재 보트에 탑승
        r--;
        answer++;
    }
    
    return answer;
}
```

