## 문제 설명
어떤 도로에 차량 신호등이 `n`개 있습니다. <br>
모든 신호등은 항상 초록불 → 노란불 → 빨간불 순서로 반복되며, 각 신호의 지속 시간은 신호등마다 다릅니다. <br>
시간은 1초부터 시작하며, 각 신호등은 처음에는 초록불 상태로 시작합니다.

이 도로에서는 가끔 정전이 일어나는데, 모든 신호등이 모두 노란불이 되면 정전이 발생한다는 사실이 밝혀졌습니다.

예를 들어 신호등이 2개이고, 각 신호등의 주기가 다음과 같다고 가정해 보겠습니다.

| 신호등 | 초록불 | 노란불 | 빨간불 |
| --- | --- | --- | --- |
| 1번 | 2초 | 1초 | 2초 |
| 2번 | 5초 | 1초 | 1초 |


<img width="611" height="131" alt="image" src="https://github.com/user-attachments/assets/c7463a32-c8d8-4c83-b726-f50163972c4c" /> <br>
위 그림과 같이 13초에 처음으로 두 신호등이 모두 노란불이 됩니다.

신호등 `n`개의 신호 주기를 담은 2차원 정수 배열 `signals`가 매개변수로 주어집니다. <br>
모든 신호등이 노란불이 되는 가장 빠른 시각(초)을 return 하도록 solution 함수를 완성해 주세요. <br>
만약 모든 신호등이 노란불이 되는 경우가 존재하지 않는다면 **-1을 return** 해주세요.

<br>

**제한사항**
- 2 ≤ `signals`의 길이 = `n` ≤ 5
  - `signals`의 원소는 `[G, Y, R]` 형태의 길이가 3인 정수 배열입니다. 순서대로 초록불, 노란불, 빨간불의 지속 시간을 의미합니다.
  - 1 ≤ `G`, `Y`, `R` ≤ 18
  - 3 ≤ `G + Y + R` ≤ 20

<br>

## 접근법

처음부터 모든 시간 별로 각 신호등의 상태를 체크해나가는 방식으로 접근을 했습니다.

먼저 `vector<pair<int, int>>` 를 하나 만들어서 거기에 각 신호등의 상태를 `<남은 시간, 상태>` 이런식으로 저장했습니다. 
`signals`에 저장된게 0 = 초록불, 1 = 노란불, 2 = 빨간불 이므로 저도 동일하게 상태를 체크했고, 
초기에는 `<초록불 시간, 0>` 이런식으로 모든 신호등에 대한 정보를 저장했숩니다.

그 이후에는 1초 부터 계속해서 체크해 나가면서 현재 상태가 노란불인지 체크하고 남은시간을 하나씩 줄이면서 진행했고, 만약 남은 시간이 0이라면 다음 상태로 업데이트 해줬습니다.
```cpp
if(v[i].first == 0) {
    v[i].second = (v[i].second + 1) % 3;    // 먼저 상태 업데이트 (초록 -> 노랑 -> 빨강 -> 다시 초록)
    v[i].first = signals[i][v[i].second];   // 이후에 남은 시간도 업데이터 해주기
}
```

또한 모든 신호등이 노란불이라면 해당 시간을 RETURN 해주는 방식입니다.
```cpp
// n = singals.size() 
// 앞서 노란불인지 체크하고 cnt에 갯수 저장
if(cnt == n) {
    return time;
}
```

위의 경우에 무한루프를 돌아서 조건이 필요하겠구나 생각했읍니다..

### 해결법
무한히 모든 시간을 확인할 필요는 없는데, 최소 어느 시점까지 돌아야할까? 에 대한 고민을 했습니다.
그래서 생각한게 모든 신호등이 끝나는 한 사이클이 존재할 것이라고 가정하고 최소공배수를 활용했읍니다.

예를 들어서, 앞에 예시로 들었던 경우에는

1번 신호등은 **5초 마다** 처음 상태로 돌아오고, <br>
2번 신호등은 **7초 마다** 처음 상태로 돌아오게 되는데 

두 신호등이 동시에 처음 상태로 돌아오는 시간은 두 숫자의 최소공배수인 **35**인 것을 알 수 있습니다. <br>
35초 동안 나올 수 있는 신호등의 전체 패턴을 다 보고 나면, 그 뒤는 똑같이 반복되기 때문에 **최대 35초까지만** 확인하면 되는 것이죵!

- 최소공배수 구하는 코드
  ```cpp
  #include <numeric>
  
  int lcm(int a, int b) { // 최소공배수 구하는 함수
      return a / gcd(a, b) * b;  // <numeric> 헤더에서 제공하는 gcd 함수를 활용!
  }
  ```

## 최종 결과

앞서 설명했던 것들을 종합해서 코드를 작성하면 최종적으로 문제를 해결할 수 있습니당.

### 최종 코드
```cpp
#include <string>
#include <vector>
#include <numeric>

using namespace std;


int lcm(int a, int b) {
    return a / gcd(a, b) * b;
}

int solution(vector<vector<int>> signals) {
    int n = signals.size();
    int limit = 1;
    
    vector<pair<int,int>> v(n);
    
    for(int i=0; i<n; i++) {
        v[i].first = signals[i][0];
        v[i].second = 0;
        
        int sum = signals[i][0] + signals[i][1] + signals[i][2];
        limit = lcm(limit, sum);
    }

    for(int time = 1; time <= limit; time++) {
        int cnt = 0;
        for(int i=0; i<n; i++){
            if(v[i].second == 1)
                cnt++;
            v[i].first--;
            if(v[i].first == 0){
                v[i].second = (v[i].second + 1) % 3;
                v[i].first = signals[i][v[i].second];
            }
        }
        
        if(cnt == n) {
            return time;
        }
    }
    
    return -1;
}
```
