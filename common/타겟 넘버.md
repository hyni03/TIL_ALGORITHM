## 문제 설명

n개의 음이 아닌 정수들이 있습니다. 이 정수들을 순서를 바꾸지 않고 적절히 더하거나 빼서 타겟 넘버를 만들려고 합니다. <br>
예를 들어 [1, 1, 1, 1, 1]로 숫자 3을 만들려면 다음 다섯 방법을 쓸 수 있습니다.

```
-1+1+1+1+1 = 3
+1-1+1+1+1 = 3
+1+1-1+1+1 = 3
+1+1+1-1+1 = 3
+1+1+1+1-1 = 3
```

사용할 수 있는 숫자가 담긴 배열 numbers, 타겟 넘버 target이 매개변수로 주어질 때 숫자를 적절히 더하고 빼서 타겟 넘버를 만드는 방법의 수를 return 하도록 solution 함수를 작성해주세요.

### 제한사항

- 주어지는 숫자의 개수는 2개 이상 20개 이하입니다.
- 각 숫자는 1 이상 50 이하인 자연수입니다.
- 타겟 넘버는 1 이상 1000 이하인 자연수입니다.

<br>

## 접근법

문제가 DFS/BFS 카테고리에 있어서 처음 보면

```text
현재 숫자를 더한다.
현재 숫자를 뺀다.
```

두 가지 경우로 계속 탐색하는 DFS가 가장 먼저 떠오를 수 있습니다.

하지만 저는 **현재까지 만들 수 있는 합을 저장하는 DP 방식**으로 풀었습니다.

숫자 하나를 사용할 때마다 현재 만들 수 있는 값에서 `+ numbers[i]`, `- numbers[i]` 두 가지 새로운 값을 만들 수 있습니다.

예를 들어

```text
numbers = [1, 2]
```

라고 하면 처음에는

```text
0
```

에서 시작해서 `1`을 사용하면

```text
+1
-1
```

이 만들어지고,

그다음 `2`를 사용하면

```text
+1 +2 = 3
+1 -2 = -1
-1 +2 = 1
-1 -2 = -3
```

이 만들어집니다.

즉, i개의 숫자를 사용했을 때 특정 합을 만드는 경우의 수를 저장해두고 다음 숫자로 경우의 수를 확장하면 됩니다.

<br>

### 음수 인덱스 처리하기

문제는 합이 음수가 될 수도 있다는 것입니다.

배열에서는 `dp[-3]` 같은 인덱스를 사용할 수 없기 때문에 모든 값에 일정한 값을 더해서 저장했습니다.

`numbers`의 전체 합을 `total_sum`이라고 하면 만들 수 있는 값의 범위는

```text
-total_sum ~ +total_sum
```

입니다.

따라서 실제 값에 `total_sum`을 더해서 배열의 인덱스로 사용합니다.

예를 들어

```text
total_sum = 5
```

라면

```text
실제 값 -5 → index 0
실제 값  0 → index 5
실제 값 +3 → index 8
실제 값 +5 → index 10
```

이런 식으로 저장할 수 있습니다.

그래서 처음 아무 숫자도 사용하지 않은 상태인 `0`은

```cpp
dp[total_sum] = 1;
```

로 시작합니다.

<br>

### 기존 풀이에서 개선할 부분

처음에는 2차원 배열을 사용했는데요.. <br>
생각해보면 `a[i][...]` 의 값을 사용해서 `a[i + 1][...]` 만 만들기 때문에 이전의 모든 DP 값을 계속 저장해둘 필요도 없습니다.

예를 들어

```text
0번째 결과 → 1번째 결과
1번째 결과 → 2번째 결과
2번째 결과 → 3번째 결과
```

만 필요합니다.

따라서 `현재 dp`, `다음 dp`두 개만 있으면 된다는 것을 깨닫고, `2차원 DP → 1차원 DP 2개`로 줄일 수 있었습니다.

<br>

## 해결법

먼저 `numbers`의 전체 합을 구합니다.

```cpp
int total_sum = 0;

for (int num : numbers)
    total_sum += num;
```

만들 수 있는 값의 범위는

```text
-total_sum ~ +total_sum
```

이므로 필요한 DP 크기는

```cpp
2 * total_sum + 1
```

입니다.

<br>

### 1. 시작 상태

아무 숫자도 사용하지 않았다면 만들 수 있는 값은 `0` 하나뿐입니다.

하지만 음수를 처리하기 위해 `total_sum`만큼 인덱스를 이동했기 때문에

```cpp
dp[total_sum] = 1;
```

로 시작합니다.

여기서 `1`은 **'합이 0이 되는 방법이 현재 한 가지 있다.'** 라는 의미입니다.

<br>

### 2. 각 숫자마다 +, - 경우 만들기

현재 숫자가 `num`이라면 현재 만들 수 있는 모든 값에 대해서 `현재 값 + num`, 현재 값 - num` 두 가지 경우를 만듭니다.

```cpp
for (int j = 0; j <= 2 * total_sum; j++) {
    if (dp[j] == 0)
        continue;

    if (j + num <= 2 * total_sum)
        next_dp[j + num] += dp[j];

    if (j - num >= 0)
        next_dp[j - num] += dp[j];
}
```

중요한 점은 `next_dp[j + num] += dp[j]`로 하나의 값에 도달하는 방법이 여러 가지일 수 있기 때문입니당.

<br>

### 3. 다음 DP를 현재 DP로 변경

현재 숫자에 대한 계산이 끝났다면

```cpp
dp = next_dp;
```

형태로 다음 계산에 사용하면 됩니다.

C++에서는 불필요한 복사를 줄이기 위해

```cpp
dp.swap(next_dp);
```

을 사용할 수 있습니다.

<br>

### 4. 최종 target 확인

실제 값 `target` 역시 `total_sum`만큼 이동해서 저장되어 있기 때문에

```cpp
dp[total_sum + target]
```

이 정답입니다.

다만

```text
target > total_sum
```

이라면 모든 숫자를 더해도 target에 도달할 수 없으므로 바로 `0`을 반환할 수 있습니다.

```cpp
if (target > total_sum)
    return 0;
```

<br>

## 최종 결과

### 최종 코드

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(vector<int> numbers, int target) {
    int total_sum = 0;

    for (int num : numbers)
        total_sum += num;

    if (target > total_sum)
        return 0;

    vector<int> dp(2 * total_sum + 1, 0);

    // 실제 값 0을 의미
    dp[total_sum] = 1;

    for (int num : numbers) {
        vector<int> next_dp(2 * total_sum + 1, 0);

        for (int j = 0; j <= 2 * total_sum; j++) {
            if (dp[j] == 0)
                continue;

            if (j + num <= 2 * total_sum)
                next_dp[j + num] += dp[j];

            if (j - num >= 0)
                next_dp[j - num] += dp[j];
        }

        dp.swap(next_dp);
    }

    return dp[total_sum + target];
}
```

## DFS로도 풀 수 있다

이 문제는 프로그래머스에서 DFS/BFS 문제로 분류되어 있어서 DFS로도 간단하게 풀 수 있습니다.

각 숫자마다 `+`, `-` 두 가지 선택지가 있으므로 다음과 같은 트리가 만들어집니다.

```text
                  0
              /       \
            +1         -1
           /  \       /  \
         +1   -1    +1   -1
         ...
```

모든 숫자를 사용했을 때 현재 합이 `target`이면 경우의 수를 하나 증가시키면 됩니다.

```cpp
// 예시 dfs?
void dfs(const vector<int>& numbers, int target,
         int idx, int sum, int& answer) {

    if (idx == numbers.size()) {
        if (sum == target)
            answer++;

        return;
    }

    dfs(numbers, target, idx + 1,
        sum + numbers[idx], answer);

    dfs(numbers, target, idx + 1,
        sum - numbers[idx], answer);
}
```

DFS 방식도 `numbers`가 최대 20개이기 때문에 충분히 사용할 수 있습니다.

하지만 처음 작성한 풀이가 DP였기 때문에 최종 코드는 기존 아이디어를 살려 DP 방식으로 개선했습니다.

<br>

## 후기

처음에는 각 숫자마다 `+`, `-` 두 가지 경우가 있으니까 그 결과를 배열에 계속 저장하면 되겠다! 하고 2차원 DP로 풀었습니다. <br>
그러나 이전의 모든 결과를 저장할 필요는 없었기 때문에 필요힌 범위만 사용할 수 있도록 1차원 DP로 줄였습니다.

그리고 이 문제는 DFS/BFS 문제로 분류되어 있어서 DFS로 풀면 코드 자체는 훨씬 간단할 거에용.. 저는 dp로 시작해버렸기에.. ㅎ

그래도 하나의 문제를 DFS뿐만 아니라 **합을 상태로 저장하는 DP 방식으로도 생각할 수 있다는 점**은 기억해두면 좋을 것 같습니다.
