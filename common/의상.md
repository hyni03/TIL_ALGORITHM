## 문제 설명

서로 다른 종류의 의상을 조합하여 입으려고 한다.

같은 종류의 의상은 최대 한 개만 착용할 수 있고, **최소 한 개의 의상은 반드시 착용**해야 한다.

의상 이름과 종류가 주어졌을 때 만들 수 있는 서로 다른 조합의 개수를 구하는 문제!

<br>

## 접근법

**`multimap<string, string>`으로 의상 종류별 의상 이름을 묶는 방법**을 생각했다.

`multimap`은 하나의 키에 여러 값을 저장할 수 있으므로, 의상 종류를 key, 의상 이름을 value로 저장하기 적합했다.

예를 들어 의상이 다음과 같다면,

```text
["yellow_hat", "headgear"]
["blue_sunglasses", "eyewear"]
["green_turban", "headgear"]
```

`multimap`에는 다음처럼 저장된다.

```text
headgear → yellow_hat
headgear → green_turban
eyewear  → blue_sunglasses
```

같은 종류에서는 한 가지 의상만 고를 수 있고, 아무것도 고르지 않는 것도 가능하다.

따라서 **각 종류에서 선택 가능한 경우의 수는 `해당 종류의 의상 개수 + 1`**이다.

모든 종류의 선택은 서로 독립적이므로 곱셈 원리를 사용하면 된다!

<br>

## 해결법

### 1. `multimap`에 의상 저장

```cpp
for (int i = 0; i < clothes.size(); i++) {
    mm.insert({clothes[i][1], clothes[i][0]});
    v.push_back(clothes[i][1]);
}
```

- `clothes[i][1]`: 의상 종류 → key
- `clothes[i][0]`: 의상 이름 → value
- `v`: 등장한 의상 종류를 기록하는 배열

`multimap`을 사용했기 때문에 동일한 종류를 키로 갖는 의상을 여러 개 저장할 수 있다.

### 2. 의상 종류 중복 제거

```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
```

의상 종류가 여러 번 등장하므로, 종류별로 딱 한 번씩 계산하기 위해 중복을 제거했다.

여기서 `unique()`는 **연속해서 등장하는 중복 원소를 뒤로 밀고 새로운 논리적 끝 위치를 반환**한다.

따라서 먼저 정렬한 뒤 `erase()`로 뒤쪽 원소를 실제로 삭제해야 한다.

```text
정렬 후:       [eyewear, headgear, headgear]
unique + erase: [eyewear, headgear]
```

### 3. 종류별 선택 가능한 경우의 수 곱하기

```cpp
for (int i = 0; i < v.size(); i++) {
    answer = answer * (mm.count(v[i]) + 1);
}
```

`mm.count(v[i])`는 해당 종류에 속한 의상의 개수를 반환한다.

여기에 `+1`을 하는 이유는 **그 종류의 의상을 입지 않는 경우**까지 포함하기 위해서다.

예를 들어 모자가 2개, 안경이 1개라면,

| 종류 | 선택 방법 | 경우의 수 |
| --- | --- | ---: |
| 모자 | 모자 A / 모자 B / 착용 X | 3 |
| 안경 | 안경 A / 착용 X | 2 |

전체 조합은 `3 × 2 = 6`가지다.

### 4. 아무것도 착용하지 않는 경우 제외

```cpp
answer = answer - 1;
```

앞에서 각 종류마다 '착용하지 않는다'라는 선택지를 포함했으므로, **모든 종류에서 아무것도 선택하지 않은 조합**이 정확히 한 번 계산된다.

하지만 문제에서는 최소 한 개의 의상을 착용해야 한다.

따라서 마지막에 `1`을 빼 주면 된다!

## 최종 결과

### 내가 작성한 코드

```cpp
#include <bits/stdc++.h>
using namespace std;

multimap<string, string> mm;
multimap<string, string>::iterator it;
vector<string> v;

int solution(vector<vector<string>> clothes) {
    int answer = 1;
    int i;

    for (i = 0; i < clothes.size(); i++) {
        mm.insert({clothes[i][1], clothes[i][0]});
        v.push_back(clothes[i][1]);
    }

    sort(v.begin(), v.end());
    v.erase(unique(v.begin(), v.end()), v.end());

    for (i = 0; i < v.size(); i++) {
        answer = answer * (mm.count(v[i]) + 1);
    }

    answer = answer - 1;
    return answer;
}
```

**주의할 점!** `mm`과 `v`가 전역 변수이므로 `solution()`을 여러 번 호출하면 이전 호출의 데이터가 남을 수 있다. 안전하게 구현하려면 두 컨테이너를 함수 내부에서 선언해야 한다. 사용하지 않는 `it`도 제거할 수 있다.

### 조금 더 간단한 풀이 (`map`)

의상 이름은 실제로 계산에 사용하지 않는다. **종류별 개수만 필요**하므로 `map<string, int>`로 처리할 수도 있다.

```cpp
#include <string>
#include <vector>
#include <map>
using namespace std;

int solution(vector<vector<string>> clothes) {
    map<string, int> cnt;

    for (const auto& item : clothes) {
        cnt[item[1]]++;
    }

    int answer = 1;
    for (const auto& [type, count] : cnt) {
        answer *= (count + 1);
    }

    return answer - 1;
}
```

별도의 중복 제거 배열이 필요하지 않고, 종류별 개수를 바로 계산할 수 있다.

## 후기

처음에는 의상을 종류별로 묶어야겠다고 생각해서 `multimap`을 사용했다.

그리고 `sort()`와 `unique()`를 통해 중복된 종류를 제거한 뒤, `count()`로 각 종류의 의상 개수를 구했는데

이 문제에서 중요한 점은 **의상을 실제로 조합하지 않아도 경우의 수를 계산할 수 있다는 것**이었다.

각 종류마다 의상을 하나 선택하거나 선택하지 않는 경우를 곱하고, 아무것도 입지 않는 경우만 마지막에 빼면 해결할 수 있다.

다만 다시 살펴보니 의상 이름까지 저장할 필요는 없었기 때문에 `map<string, int>`로 개수만 관리하면 코드가 훨씬 간단해지는 거시다~
