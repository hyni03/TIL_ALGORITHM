# 2026년 9월 27일 TIL - [LV2] 2022 KAKAO BLIND RECRUITMENT / 주차 요금 계산

링크: https://school.programmers.co.kr/learn/courses/30/lessons/92341

## 문제 설명

주차장의 요금표와 차량이 들어오고(입차) 나간(출차) 기록이 주어졌을 때, 차량별로 주차 요금을 계산하려고 합니다. 

주차 요금을 나타내는 정수 배열 `fees`, 자동차의 입/출차 내역을 나타내는 문자열 배열 `records`가 매개변수로 주어집니다. <br>
차량 번호가 작은 자동차부터 청구할 주차 요금을 차례대로 정수 배열에 담아서 return 하도록 solution 함수를 완성해주세요.

(문제 설명이 너무 긴 관계로 자세한 내용은 생략하겠읍니다.. - 링크 참고)

<br>

## 접근법

이 문제에서 해야 할 일은 크게 네 가지입니다.

```text
1. HH:MM 형태의 시간을 분으로 변환
2. 차량별 입차 시간 저장
3. 출차할 때마다 누적 주차 시간 계산
4. 누적 시간에 따라 최종 요금 계산
```

차량 번호별로 데이터를 저장해야 하기 때문에 `map`을 사용했습니다.

```cpp
map<string, int> in_times;
map<string, int> parking_times;
```

`in_times`에는 현재 주차장에 들어와 있는 차량의 **입차 시간**을 저장하고,

`parking_times`에는 차량별 **누적 주차 시간**을 저장합니다.

그리고 `map`은 key를 기준으로 정렬된 상태를 유지하기 때문에 마지막에 `parking_times`를 순회하면 자연스럽게 차량 번호가 작은 순서대로 결과를 만들 수 있습니다.

<br>

## 해결법

### 1. 시간을 분으로 변환

주차 시간을 계산하려면 `"05:34"` 같은 문자열을 그대로 사용하기보다 분 단위의 정수로 바꾸는 것이 편리하기 떄문에 <br>
시간 변환 함수를 따로 만들었습니다.

```cpp
int calc_time(const string& time) {
    int hour = stoi(time.substr(0, 2));
    int minute = stoi(time.substr(3, 2));

    return hour * 60 + minute;
}
```

<br>

### 2. 기록 파싱

문제에서 record의 형식은 항상

```text
HH:MM 차량번호 IN/OUT
```

으로 고정되어 있습니다.

또한 차량 번호는 항상 4자리이기 때문에 위치를 이용해서 바로 잘라낼 수 있습니다.

```cpp
string time_str = record.substr(0, 5);
string car_id = record.substr(6, 4);
string status = record.substr(11);
```

<br>

### 3. IN / OUT 처리

입차 기록이라면 현재 시간을 `in_times`에 저장합니다.

```cpp
if (status == "IN") {
    in_times[car_id] = time;
}
```

출차 기록이라면 현재 시간에서 입차 시간을 빼서 누적 주차 시간에 더해줍니다.

```cpp
else {
    parking_times[car_id] += time - in_times[car_id];
    in_times.erase(car_id);
}
```

같은 차량이 다시 입차할 수도 있으므로 `parking_times`에는 기존 값을 덮어쓰는 것이 아니라 계속 누적해줘야 합니다

<br>

### 4. 출차 기록이 없는 차량 처리

모든 기록을 처리한 뒤에도 `in_times`에 남아있는 차량은 출차 기록이 없는 차량이므로 <br>
문제 조건에 따라 이런 차량은 모두 `23:59`에 출차한 것으로 처리합니다.

```cpp
int end_time = calc_time("23:59");

for (const auto& iter : in_times) {
    parking_times[iter.first] += end_time - iter.second;
}
```

<br>

### 5. 주차 요금 계산

누적 주차 시간이 기본 시간 이하라면 기본 요금만 내면 됩니다.

```cpp
int fee = fees[1];
```

기본 시간을 초과하면

```text
초과 시간 = 누적 시간 - 기본 시간
```

을 구한 뒤 단위 시간으로 나눕니다.

이때 나누어 떨어지지 않으면 올림해야 합니다.

정수 나눗셈에서는 다음 공식을 사용하면 `ceil()` 없이 올림을 처리할 수 있습니다.

```text
(a + b - 1) / b
```

따라서

```cpp
int extra_time = parking_time - fees[0];

fee += ((extra_time + fees[2] - 1) / fees[2]) * fees[3];
```

로 계산할 수 있습니다.

<br>

## 최종 결과

### 최종 코드

```cpp
#include <string>
#include <vector>
#include <map>

using namespace std;

int calc_time(const string& time) {
    int hour = stoi(time.substr(0, 2));
    int minute = stoi(time.substr(3, 2));

    return hour * 60 + minute;
}

int calc_fee(int parking_time, const vector<int>& fees) {
    int fee = fees[1];

    if (parking_time <= fees[0])
        return fee;

    int extra_time = parking_time - fees[0];

    fee += ((extra_time + fees[2] - 1) / fees[2]) * fees[3];

    return fee;
}

vector<int> solution(vector<int> fees, vector<string> records) {
    vector<int> answer;

    map<string, int> in_times;
    map<string, int> parking_times;

    for (const string& record : records) {
        string time_str = record.substr(0, 5);
        string car_id = record.substr(6, 4);
        string status = record.substr(11);

        int time = calc_time(time_str);

        if (status == "IN") {
            in_times[car_id] = time;
        }
        else {
            parking_times[car_id] += time - in_times[car_id];
            in_times.erase(car_id);
        }
    }

    int end_time = calc_time("23:59");

    for (const auto& iter : in_times) {
        parking_times[iter.first] += end_time - iter.second;
    }

    for (const auto& iter : parking_times) {
        answer.push_back(calc_fee(iter.second, fees));
    }

    return answer;
}
```
